# Logos das emissoras (Próximos jogos)

Coloque aqui os arquivos de logo (SVG de preferência, ou PNG com fundo
transparente). O app usa automaticamente quando o arquivo existir; se faltar,
mostra um chip colorido com o nome da emissora.

Arquivos esperados:
- globo.svg  → TV Globo
- sbt.svg    → SBT
- caze.svg   → CazéTV

Os nomes/paths estão em `lib/broadcasters.ts` (campo `logo`).
